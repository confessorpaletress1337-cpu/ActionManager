# ActionManager

Планировщик автоматического выключения компьютера на .NET 8 + Avalonia (MVVM).

## Как это работает

- Расписание живёт в **Windows Task Scheduler** и управляется напрямую через
  библиотеку `TaskScheduler` (typed API над COM `taskschd.dll`) — никаких
  `schtasks.exe` и строк-команд.
- Задача `ActionManager\AutoShutdown` — ежедневный триггер, который за три минуты
  до заданного времени запускает **само приложение с аргументом**
  `--scheduled-shutdown`. UI не открывается; предупреждение показывает Windows.
- Задача работает в интерактивном сеансе текущего пользователя: окно ActionManager
  можно закрыть, но пользователь должен оставаться вошедшим в Windows.
- Значение по умолчанию — **19:00**. За 3 минуты до выбранного времени Windows
  показывает системное предупреждение; выключение можно отменить в приложении
  или штатной командой `shutdown /a`.
- **Отмена на конкретный день** хранится в настройках
  (`%LocalAppData%\ActionManager\options.json`, список дат). Когда сработавший
  планировщик запускает приложение, оно сначала проверяет: если сегодняшняя
  дата в списке отмен — выключение пропускается.
- Если настройки повреждены или недоступны, приложение действует безопасно:
  записывает ошибку в журнал и **не выключает компьютер**. Сохранение JSON
  выполняется через временный файл, чтобы планировщик не увидел частичную запись.
- Все команды системе (shutdown/сон/гибернация/блокировка/логаут) — только в
  `Services/SystemCommandsService`, из ViewModel напрямую ничего не вызывается.

## Структура

```text
Program.cs                  — точка входа: разбор аргументов планировщика до старта UI
App.axaml(.cs)              — конфигурация приложения и ручная сборка сервисов
Views/MainWindow.axaml(.cs) — окно (код-бехайнд минимальный)
ViewModels/
  MainWindowViewModel       — расписание, статусы, команды
  CalendarViewModel         — месячная сетка календаря
  CalendarDayViewModel      — ячейка дня (состояния: план/отмена/прошло/выкл)
Services/
  SystemCommandsService     — ВЕСЬ доступ к системе (shutdown.exe, WinAPI)
  TaskSchedulerService      — обёртка над Windows Task Scheduler
  JsonOptionsStore          — локальные настройки (JSON)
  AppLog                    — журнал %LocalAppData%\ActionManager\actions.log
Themes/                     — палитра и styles
```

## Запуск

```powershell
dotnet run
```

Первый запуск создаёт отключённую по умолчанию задачу в планировщике.
Дальше в окне: выставляешь время, включаешь тумблер — готово. Проверить можно
в `taskschd.msc` (или кнопкой «Открыть планировщик Windows» в приложении).

## Тестирование безопасно

1. Поставь время на 2–3 минуты вперёд и включи тумблер.
2. Отмени сегодняшнее выключение кликом по сегодняшнему дню и кнопкой отмены —
   в момент срабатывания задачи ничего не произойдёт, в `actions.log` появится
   строка «отменено пользователем».
3. Верни отмену — на следующий день план продолжит работать.

## Ограничения

- Если приложение переименовано/перенесено — пересоздай расписание
  (в задаче хранится путь к exe).
- Планировщик **будит комп из сна не умеет и не должен** (шатдаун-задача), а
  включение из полностью выключенного состояния — только через BIOS RTC Alarm /
  Wake-on-LAN, это вне Windows.
